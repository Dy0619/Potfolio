# D.Lune 포트폴리오

`index.html`을 열면 포트폴리오가 실행됩니다.

프로젝트의 **사이트 방문** 버튼도 사용하려면 `index.html`과 `projects` 폴더를 같은 위치에 보관해주세요.

```text
index.html
projects/
  fresh-note.html
  cue.html
  before-curtain/
    index.html
    guide.html
    app.js
    performances.js
    styles.css
downloads/
  shade-korea-work-in-progress.zip
assets/
  profile-photo.jpg
```

- `projects/fresh-note.html`: 업로드한 최신 Fresh Note 원본
- `projects/cue.html`: 업로드한 최신 CUE 원본
- `projects/before-curtain/`: 업로드한 BEFORE-CURTAIN-v4.2 원본 5개 파일. 같은 폴더에 함께 보관해야 검색·가이드 이동이 동작합니다.
- 프로젝트 소개·상세 설명·화면 캡처와 폴더 썸네일은 이 버전에 맞춰 업데이트했습니다.
- 포트폴리오의 사진과 미리보기 이미지는 `index.html`에도 포함되어 있습니다.

GitHub에서 **Code → Download ZIP**으로 전체 파일을 받아 압축을 푼 뒤 실행하면 프로젝트 연결 경로가 유지됩니다. 웹에 배포할 때도 같은 폴더 구조를 유지해주세요.

Fresh Note의 관리 기록, CUE의 MY CUE 기록과 Before Curtain의 관람 준비 체크리스트는 사용하는 브라우저에 저장됩니다. 다른 기기나 브라우저로 자동 동기화되지 않으므로 각 앱의 내보내기·백업 기능으로 보관해주세요.

## 인트로

- 약 4.6초 동안 금빛 입자가 모이고, 소개 문장이 나타난 뒤 본문과 같은 밤하늘로 이어집니다. 움직임 줄이기 설정에서는 정적인 문구를 약 2.5초 표시합니다.
- 금빛을 기본으로 봄 꽃잎, 여름 반딧불, 가을 낙엽, 겨울 눈 결정의 색과 움직임을 섞습니다. 서울 기준 월로 계절을 정합니다.
- 소개 문장은 실제 HTML 텍스트이며, 입자는 장식용 캔버스에 표시합니다. 작은 화면에서는 문장을 세 줄로 배치합니다.
- 음악은 선택 기능입니다. **음악과 함께 보기**를 누르면 시작되며 음악 준비와 인트로 전환은 별개로 동작합니다.
- 처음 방문하면 인트로가 재생됩니다. 끝까지 보거나 건너뛰면 방문 기록을 남깁니다.
- 같은 브라우저에서 같은 주소로 다시 열면 인트로 없이 본문이 바로 표시됩니다.
- 상단의 **인트로 다시 보기** 버튼으로 언제든 재생할 수 있습니다.
- 계절별 미리보기 선택창은 제거했으며, 인트로의 계절은 현재 날짜에 따라 자동으로 적용됩니다.

## 계절별 별자리와 음악 반응

- 한국의 계절 구분(서울 기준 월)에 맞춰 봄 사자자리, 여름 백조자리, 가을 페가수스자리·대사각형, 겨울 오리온자리를 자동 적용합니다.
- 모양 중심의 별자리 도식이며 실제 관측 시각·방위의 하늘 지도는 아닙니다. 가을철 대사각형의 알페라츠는 안드로메다자리에 속합니다.
- 달 주변에도 크기가 다른 작은 별을 흩어 배치했습니다. 위치는 유지하고 저음·중음·고음과 박자에 맞춰 밝기와 빛 번짐이 달라집니다. 작은 화면에서는 별의 수를 줄입니다.
- 음악이 재생되면 실제 주파수·저음 변화에 따라 별자리와 달 주변 별빛이 함께 반응합니다. 정지하면 별과 연결선은 정적인 형태로 남습니다.
- 기존 음악 파일 `bgm.m4a`를 `index.html`과 같은 폴더에 두면 됩니다. 음악 파일은 저장소에 포함하지 않았습니다.
- 별빛 버튼으로 움직임을 끌 수 있으며, 운영체제의 동작 줄이기 설정도 따릅니다.

## 첫 화면과 읽기 편의

- 첫 화면의 **프로젝트 보기**는 프로젝트 폴더를 바로 엽니다. **기록 따라 내려가기**는 자기소개부터 이동합니다.
- 소개 문장과 본문 크기·행간을 정리하고, 글자 뒤에만 어두운 그라데이션을 적용했습니다.
- 오른쪽 캐릭터의 **캐릭터 접기** 버튼을 누르면 작은 달 버튼만 남습니다. 같은 브라우저에서 접은 상태를 기억하며, 달 버튼으로 다시 펼칠 수 있습니다.
- 큰 달은 화면 중앙의 고정 배경으로 표시됩니다. 페이지를 아래로 스크롤하면 초승달에서 반달, 보름달로 차오르고, 위로 올리면 다시 비워집니다. 맨 아래에서는 보름달이 완성됩니다.
- 기존 오른쪽 배경 달과 하단의 작은 진행 달은 중앙 달로 통합했습니다. 모바일에서는 달 크기를 줄이고, 별자리와 중앙 빛줄기의 밝기를 조절해 본문을 읽기 편하게 유지합니다.

- 중앙 달은 첫 화면에서도 알아볼 수 있도록 초승달의 최소 밝은 면적을 10%로 유지합니다. 상단의 가로 스크롤 진행선은 제거하고, 중앙 달로만 읽기 진행을 표시합니다.

- 중앙 달의 밝은 면은 왼쪽에서 오른쪽으로 차오릅니다. 위로 스크롤하면 오른쪽부터 비워집니다.

- 달은 실제 달처럼 섬세한 요철과 금빛 가장자리가 있는 생성 이미지로 표시합니다. 이미지가 HTML에 내장되어 별도로 연결할 필요가 없으며 원본 웹용 파일은 assets/moon-golden-texture.webp에 있습니다. 마지막 폴더 아래에는 화면 높이에 맞는 여백을 두어 중앙 빛줄기가 끝까지 도달하고 보름달을 볼 수 있도록 했습니다.

- 달 전체의 범위를 미리 보여주는 어두운 원판과 고정 원형 후광은 제거했습니다. 스크롤로 드러나는 달의 질감과 그 부분에서 번지는 빛만 표시합니다.

## 프로젝트와 작업 노트

- 프로젝트 폴더에는 Fresh Note, CUE, Before Curtain을 소개합니다. Before Curtain은 실제 첫 화면·관람 가이드 미리보기, 상세 설명, 사이트 방문으로 연결됩니다.
- Before Curtain의 공연 자료는 업로드한 4.2 버전에 포함된 자료이며 실시간 예매 정보가 아닙니다. 최신 공연 일정과 입장 규정은 각 공식 안내에서 확인합니다.
- 기존 ‘작업 모음’은 ‘작업 노트’로 바꾸었습니다. SHADE KOREA는 ‘잠시 멈춤’, 인물 사전은 ‘기획 · 틀 단계’로 표시합니다.
- SHADE KOREA의 설명은 업로드한 5.17 코드를 기준으로 작성했습니다. 실제 경로 입력 화면을 미리 보여주고 작업 파일을 내려받을 수 있습니다. 정적 포트폴리오에서는 지도 API나 서버가 필요한 기능을 직접 실행하지 않습니다.
- SHADE KOREA 작업 파일에는 로컬 `.env`를 넣지 않았습니다. 압축을 풀고 포함된 README와 `.env.example`을 참고해 지도·경로 API 설정을 준비한 뒤 Node.js 서버로 실행합니다.
- 인물 사전은 기획과 화면 틀을 잡아둔 초기 단계로 소개하며 실행 링크는 제공하지 않습니다.

- 프로젝트 폴더의 세 미리보기는 표지 뒤에 넣고 폴더 내부에서만 표시합니다. 마우스·키보드로 선택하거나 폴더를 열어도 표지 문구를 가리지 않습니다.
